## Run the Notebook

Install the dependencies from the repository root:

```bash
python3 -m pip install -r requirements.txt
```

Then start Jupyter from the `notebook` directory so the relative data path resolves exactly as submitted:

```bash
cd notebook
jupyter notebook Xiong_Zexin_HW2.ipynb
```

Restart the kernel and run all cells in order before reviewing the results.
